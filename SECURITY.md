# Security policy

This repository contains **deliberately vulnerable** code for security research. The planted vulnerabilities (A1–A12 in [docs/attack-matrix.md](docs/attack-matrix.md)) are intentional and gated by feature flags. Please don't report them.

If you find an **unintended** issue, for example a real secret, a flaw in the hardened build or a safety control that doesn't work, please open a [private security advisory](https://github.com/willvelida/ai-agent-redteam-lab/security/advisories/new).
